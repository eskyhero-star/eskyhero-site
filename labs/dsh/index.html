🧠 DSH 控制台

DeepSeek Harness 是一个跑在你自己机器上的 AI 工作台。它带会话、文件读写和终端执行能力，因此不适合公开挂在公网上。

为什么这里没有登录框

原来的口令页依赖主机上的反向代理接口（check / latest-token）。这个页面现在托管在纯静态的 GitHub Pages 上，没有后端可调用，所以只保留使用说明。

怎么在本机打开

  1. 在主机上运行 dsh web
  2. 终端会打印一条带 token 的地址，直接点开
  3. 需要重新取口令时，执行下面这行，取最后一条
grep -aoE "token=[A-Za-z0-9_-]+" ~/.dsh/logs/runtime.log | tail -1
安全提醒：这个服务能执行命令、读写文件。请只在本机或内网使用，不要为它配置公网域名；远程访问请走 SSH 隧道或 VPN。
